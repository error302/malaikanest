1. Design Skills Compliance & Engineering Rules

This design satisfies the strict guidelines from our frontend skills, UI/UX skills, and Obsidian knowledge base:

Directive Rule Applied Source
Zero Emojis All icons rendered via stroke-consistent SVG paths (Phosphor / Feather). Zero emoji glyphs in markup or copy. design-taste-frontend §3.D
Palette Discipline Oatmeal canvas (#FAF8F5), Umber text (#2D2926), single terracotta accent (#C96E4B), sand border (#ECE7E1). design-taste-frontend §4.2
Tactile Feedback Buttons scale down to active:scale-[0.97] with 160ms cubic-bezier(0.23, 1, 0.32, 1) ease-out. emil-design-eng §Component Principles
Touch Targets All interactive elements (dock tabs, filter pills, quick-add buttons) maintain min-h-[44px]. Mobile App UI Design.md
Floating Bottom Dock 21st.dev Expandable Tabs floating pill dock with spring transitions and safe-area inset support. 21st Dev UI UX Design Skills.md §4

2. Implementation Roadmap

To implement this clean, emoji-free, high-craft mobile frontend on Malaika Nest:

  • Template 1: backend/templates/storefront/base.html — Replace the fixed square bottom bar with the 21st floating bottom dock pill, update the CSS theme tokens to the Baby Mori oatmeal foundation, and ensure all icons are native inline SVG paths.
  • Template 2: backend/templates/storefront/home.html — Redesign the mobile hero and categories with the horizontal milestone pill selector, dynamic free delivery banner, and clean 2-column card grid.
  • Template 3: backend/static/css/storefront.css — Compile Tailwind utilities for the smooth cubic-bezier transitions and active scale states.
