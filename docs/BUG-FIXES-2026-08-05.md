## Why each mattered

- **Icon shim (#1):** the `lucide-react → src/lib/icons.tsx` alias is load-bearing for ~70 files.
  Editing every `ui/*` import would be churn; adding aliases in one place is surgical.
- **Cart add (#2):** the second arg was silently dropped at runtime (qty defaulted to 1 anyway), so
  behavior was unchanged — but it signalled a stale API assumption. Fixed to match the real signature.
- **Wishlist ids (#3):** thrifted products use Prisma cuid *string* ids; regular products use
  *number* ids. The context now accepts both and compares by `String()` to avoid `5 !== "5"` bugs.
- **`db.product` (#10):** products are in Django/Postgres, not the Prisma SQLite CMS. The model
  never existed; `llms.txt` now fetches the live count from the API (wrapped in `safe()` so a down
  API just omits the line).
