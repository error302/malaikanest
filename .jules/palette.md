## 2024-05-24 - Accessibility improvements for lists with duplicate action labels
**Learning:** For lists containing identical action buttons (e.g., 'Remove' items in a cart), screen readers will repeatedly read the exact same label (e.g., "Remove, button", "Remove, button"). This provides insufficient context, and string concatenation with translated keys (e.g. `t('cart.remove') + ' -'`) creates confusing ARIA labels. The i18n system allows interpolation with `{variable_name}`, which is much better for building context-specific ARIA labels.
**Action:** When adding `aria-label` attributes for accessibility to items in a list, always use the translation engine's interpolation feature to provide complete, context-specific descriptions (e.g., `aria-label={t('cart.removeItem', { name: item.name })}`) rather than simply translating a generic verb. Avoid string concatenation.
