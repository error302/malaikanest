## 2026-10-10 - Refactoring translation keys for accessibility
**Learning:** Hardcoded string concatenation with translation strings (e.g. `t('cart.remove') + ' -'`) yields poor accessibility names for screen readers because it creates vague generic names like "Remove -". Also, using generic labels like "Remove" for items in a list without identifying the item is an accessibility violation.
**Action:** When adding `aria-label` attributes for accessibility, use the translation engine's interpolation feature `t('cart.decreaseQty', { name: item.name })` instead of string concatenation, so the result is a context-rich label like "Decrease quantity of Blue Shirt". We need to add explicit entries like `cart.decreaseQty`, `cart.increaseQty`, and `cart.removeItem` to the dictionary, rather than relying on generic 'remove' strings.
