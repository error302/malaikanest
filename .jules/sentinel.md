## 2026-09-14 - [SSRF in Image Downloading]
**Vulnerability:** Found an unauthenticated Server-Side Request Forgery (SSRF) vulnerability in the admin endpoints for downloading product and category images via URL. The `requests.get()` call was blindly following user-supplied URLs without scheme or hostname validation.
**Learning:** In Django/DRF, anytime external URLs are accepted as input and fetched server-side (like importing images via URL), it introduces a potential SSRF risk. The codebase needs a standard utility or explicit guardrails whenever making outgoing HTTP requests based on user input.
**Prevention:** Implement strict URL scheme validation (e.g., `https` only) and validate the hostname against a whitelist of trusted domains (e.g., Cloudinary CDN). Additionally, use `allow_redirects=False` with `requests.get()` to prevent attackers from bypassing the hostname check using an open redirect on the trusted domain.
