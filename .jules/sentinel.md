## 2026-09-11 - SSRF Vulnerability in Admin Image Downloads
**Vulnerability:** `AdminCategorySerializer` and `AdminProductSerializer` allowed arbitrary Server-Side Request Forgery (SSRF) when downloading images from an admin-provided URL, bypassing domain validation. The default `requests.get()` would resolve internal hostnames or follow open redirects.
**Learning:** Admin inputs, even in serializers intended for internal staff, must be strictly validated. Furthermore, simply checking the hostname before the request is insufficient if `allow_redirects=True` (the default) allows attackers to supply an external URL that redirects to internal metadata endpoints.
**Prevention:** Always parse the URL to enforce a specific scheme (`https`), validate the hostname against a whitelist (`IMAGE_URL_ALLOWED_HOSTS`), AND explicitly set `allow_redirects=False` on `requests.get()` calls.
